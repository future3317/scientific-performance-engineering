# Evidence scope

Historical formal receipts, September freeze and manuscript numerical artifacts
remain immutable. Historical absence of verifier results is missing stage
information, not scientific failure. D's twenty unlaunched cells are missing
potential outcomes, not zero utility.

New state tracking, contrastive mining, bounded editing and regime classification
are implementations and hypotheses until new independent real-task comparisons
exist. Mock/synthetic success demonstrates implementation behavior only.

New study arms use descriptive names, never redefine historical A/B/C/D. Agent
improvement, skill-content improvement and routing improvement are distinct
estimands. A rewritten skill invalidates its former support certificate.
