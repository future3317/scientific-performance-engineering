# ACRE-v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a minimal, auditable Active Causal Rule Evolution layer without changing existing SPE-EvoBench behavior: first normalize evidence and relation schemas, then add deterministic predicate synthesis with statistical CEGIS for two boundary families.

**Architecture:** The canonical model remains the single source of truth. Evidence v2 stores multi-intervention assignments and an explicit representative/adversarial stream; legacy single-rule evidence is converted at the read boundary and is never maintained as a second internal representation. Predicate synthesis enumerates a finite grammar from observed context values, removes only statistically certified counterexamples, and returns `unsynthesizable_boundary` when the grammar cannot express the certified boundary. BoundaryBench fixtures are deterministic and independent of the existing v1.0-20 task stream.

**Tech Stack:** Python 3.11, stdlib dataclasses/JSON, existing schema generator, deterministic synthetic fixtures, and the project-specific `D:\Anaconda\envs\EGNN\python.exe` environment.

## Global Constraints

- Do not change the existing benchmark task manifests, verifier semantics, scoring, formal campaign, or v1.0-20 results.
- Keep factorial interaction, active acquisition, and ConservativeCausalRouter as isolated ACRE pilot components; they must not alter the formal benchmark.
- Do not keep a parallel legacy internal model; legacy evidence is normalized once at the input boundary.
- Predicate synthesis is deterministic; model-generated text cannot define canonical predicate semantics.
- Representative evidence is the only evidence stream eligible for promotion; adversarial evidence can only falsify, quarantine, specialize, or request confirmation.
- Every new test must be written and observed failing before its production implementation.

## ACRE-v0 stages 3--5

### Task 3: Factorial interaction engine

**Files:**
- Create: `core/acre/factorial.py`
- Create: `benchmark/interaction/factorial_bench.py`
- Create: `benchmark/interaction/test_factorial.py`

The engine consumes complete randomized 2x2 blocks, computes $Z=u_{11}-u_{10}-u_{01}+u_{00}$, maintains a bounded mean confidence interval for $Z/4$, and classifies synergy, antagonism, independence, or prerequisite. A deterministic coverage simulation checks the interval contract. It does not write relation state or alter the formal benchmark.

**Files:**
- Create: `core/acre/acquisition.py`
